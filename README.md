# 9급 문제은행

2027 지방직 9급(행정직) 대비 개인용 웹앱. 기출을 한 문제씩 풀고 바로 채점한다.

- 과목: 국어 · 영어 · 행정법 · 행정학
- 출제: 지방직 9급 실측 영역 비율(BLUEPRINT) → 급수 비율(9급 80 / 7급 20) → 오답률 높은 단원 우선, 쿨다운 60일(영어 120일)
- 기록은 브라우저(localStorage)에만 저장된다. 통계 화면에서 백업 파일로 옮긴다.
- 홈 화면에 추가하면 오프라인에서도 동작한다.

`data/*.json`은 PC의 문제은행(`9급\앱\export.py`)에서 내보낸 것이다. 기출 문항의 저작권은 각 시행처(인사혁신처·지방자치단체 등)에 있다.
